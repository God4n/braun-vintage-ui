Components built like an instrument panel

A collection of web components in plain HTML and CSS, inspired by industrial design from the 1960s to the 80s: neutral surfaces, square corners, knobs, graduated scales and an orange that only lights up when something is live. Every page shows the component working and the code to copy.

System rules
Orange is a pilot light
It marks what is live, active or the main action. One orange primary action per view.
Square corners
Zero radius everywhere. Only knobs, lamps and process nodes are round.
Graduated scales
Every continuous value is read against a row of ticks: knobs, bars, sliders and readouts.
Three surface levels
Paper behind, bordered panel on top, sunken area inside. Never two alike without a border.
Selected means sunken
The active tab or row takes the page colour, or inverts like a pressed key.
Dashed means create
A dashed border always means a gap to fill or something to add.
A side stripe for state
2 to 5 px, on the left or top, always paired with text or a glyph.
Tabular figures
Any number that changes or gets compared uses tabular-nums; machine data is set in mono.

Accessible text
  • In light mode --steel, --signal, --ok and --sev-medium fall short of 4.5:1 as small text. Use the -text variants for lettering; the base colours are for fills, borders, dots and stripes.
  • Yellow is never text in light mode: use it as a fill with --ink on top.
  • Series order in a chart: ink, signal, blue, green, yellow, brown, teal.
  • Tints are derived with color-mix instead of new tokens: 8–10% over --panel for backgrounds, 45% over --line for borders.
  • A component with state takes its colour from the local variable --sc, for example style="--sc: var(--sev-critical)".
